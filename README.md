# Aplicación Matemática para Resolución de Ejercicios

## Introducción

Las matemáticas forman parte fundamental de la educación y del desarrollo del pensamiento lógico. Sin embargo, para muchas personas aprender matemáticas puede resultar complicado debido a la manera en que normalmente se enseñan. En muchos casos, los estudiantes aprenden únicamente a memorizar procedimientos y fórmulas sin comprender realmente el razonamiento detrás de cada operación.

Cuando comienzan a aparecer temas más complejos como álgebra, derivadas, integrales o ecuaciones simbólicas, la dificultad aumenta aún más. Esto provoca frustración, desmotivación e incluso la idea equivocada de que algunas personas “no sirven” para las matemáticas.

Debido a esta problemática surge la idea de desarrollar una aplicación matemática que funcione como una herramienta de apoyo para estudiantes, permitiendo resolver ejercicios de forma más sencilla, rápida y accesible mediante el uso de programación y librerías matemáticas especializadas.

---

# Planteamiento del Problema

Actualmente muchos estudiantes presentan dificultades para resolver operaciones matemáticas debido a la falta de comprensión de conceptos básicos y al aprendizaje basado únicamente en la memorización.

Además, existen herramientas demasiado complejas o poco accesibles para quienes apenas están aprendiendo. Algunas aplicaciones requieren conocimientos avanzados, conexión constante a internet o incluso el uso de inteligencia artificial, lo que puede dificultar su uso para ciertos usuarios.

Por ello, se busca desarrollar una aplicación sencilla y funcional que permita resolver operaciones matemáticas utilizando únicamente instrucciones de texto, ayudando a los estudiantes a practicar y comprobar resultados de manera rápida y práctica.

---

# Justificación

La creación de esta aplicación tiene como propósito brindar una herramienta accesible que facilite la resolución de ejercicios matemáticos y apoye el aprendizaje de estudiantes que presentan dificultades en esta área.

El proyecto también permite aplicar conocimientos de programación, bases de datos y álgebra computacional mediante librerías especializadas como `math` y `SymPy`.

Además, al tratarse de una aplicación enfocada en operaciones matemáticas y álgebra simbólica, representa una forma práctica de combinar programación con educación.

---

# Objetivo General

Desarrollar una aplicación matemática capaz de resolver diferentes tipos de operaciones y expresiones utilizando librerías especializadas, ofreciendo una herramienta práctica y accesible para apoyar el aprendizaje y la práctica de matemáticas.

---

# Objetivos Específicos

- Implementar operaciones matemáticas básicas y avanzadas.
- Resolver ecuaciones algebraicas.
- Calcular derivadas e integrales.
- Simplificar expresiones matemáticas.
- Utilizar álgebra simbólica mediante `SymPy`.
- Crear un sistema de usuarios conectado a una base de datos.
- Permitir guardar ejercicios e historiales.
- Diseñar una interfaz sencilla y fácil de utilizar.

---

# Descripción del Proyecto

El proyecto consiste en el desarrollo de una aplicación matemática enfocada en resolver distintos tipos de ejercicios mediante programación.

La aplicación utiliza librerías matemáticas especializadas para realizar cálculos de manera automática y eficiente. Entre sus funciones principales se encuentran:

- Operaciones básicas.
- Resolución de ecuaciones.
- Derivadas.
- Integrales.
- Simplificación de expresiones.
- Álgebra simbólica.
- Manejo de usuarios.
- Guardado de ejercicios en historial.

El sistema funciona mediante instrucciones ingresadas por texto, permitiendo que el usuario escriba operaciones o expresiones matemáticas directamente en la aplicación.

---

# Tecnologías Utilizadas

## Lenguaje de Programación

- Python

## Librerías

### Math

La librería `math` permite realizar operaciones matemáticas básicas y avanzadas como:

- Raíces cuadradas
- Potencias
- Funciones trigonométricas
- Logaritmos

### SymPy

`SymPy` es una librería de álgebra simbólica utilizada para:

- Resolver ecuaciones
- Simplificar expresiones
- Calcular derivadas
- Resolver integrales
- Manipular expresiones algebraicas

## Base de Datos

La aplicación incluye una base de datos para almacenar usuarios e historiales de ejercicios.

---

# Funcionamiento de la Aplicación

El funcionamiento general de la aplicación es el siguiente:

1. El usuario inicia sesión o crea una cuenta.
2. Ingresa una operación matemática mediante texto.
3. La aplicación procesa la operación utilizando las librerías matemáticas.
4. Se muestra el resultado en pantalla.
5. El usuario puede guardar el ejercicio en el historial.

---

# Características Principales

## Resolución de Operaciones

La aplicación puede resolver operaciones matemáticas básicas como:

- Suma
- Resta
- Multiplicación
- División

- Raíces
