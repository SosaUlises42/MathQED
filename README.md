# 📘 Proyecto Math QED

## 📌 Descripción del Proyecto

Muchas personas tienen dificultades para aprender matemáticas porque, en muchos casos, solo se enseñan procedimientos mecánicos sin explicar realmente el razonamiento detrás de ellos. Conforme aparecen fórmulas, letras y operaciones más complejas, resulta más difícil comprender los temas si las bases no quedaron claras.

Además, practicar matemáticas puede volverse aburrido o frustrante, haciendo que muchos estudiantes lleguen a pensar que “no sirven” para la materia, cuando en realidad solo necesitan una herramienta más clara, práctica y accesible para aprender.

Por esta razón se desarrolló esta aplicación, con el objetivo de ayudar a resolver ejercicios matemáticos de manera sencilla y práctica, funcionando como una herramienta de apoyo para estudiantes.

---

# ⚙️ Funcionalidades

La aplicación está desarrollada utilizando Python y librerías matemáticas como:

- `math`
- `SymPy`

Entre sus principales funciones se encuentran:

- Resolver operaciones matemáticas básicas
- Resolver ecuaciones
- Calcular derivadas
- Calcular integrales
- Simplificar expresiones algebraicas
- Trabajar con álgebra simbólica
- Registro de usuarios en base de datos
- Guardado limitado de ejercicios o proyectos
- Historial básico de operaciones

---

# 🗄️ Base de Datos

La aplicación permite almacenar usuarios y guardar ciertos ejercicios realizados para que puedan continuarse posteriormente.

Esto funciona como un pequeño historial o sistema de proyectos matemáticos.

---

# ⚠️ Limitaciones

Actualmente la aplicación tiene algunas limitaciones importantes:

- No utiliza inteligencia artificial
- No admite imágenes ni fotografías
- Todas las operaciones deben ingresarse mediante texto
- No muestra procedimientos completos paso a paso
- Está pensada como herramienta de apoyo y no como plataforma educativa completa

---

# 🎯 Objetivo

El objetivo principal es facilitar la resolución de ejercicios matemáticos y brindar una alternativa práctica para estudiantes que necesiten apoyo en temas de matemáticas y álgebra simbólica.
